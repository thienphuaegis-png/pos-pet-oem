1. File Tĩnh (JS / CSS)

Đã nằm trên Vercel Edge CDN (Hong Kong). Mở trang không còn kéo code giao diện qua máy tiệm.
Nút thắt băng thông

2. Đường Hầm Tailscale Funnel

Mọi lệnh /api/* đi qua Funnel miễn phí (~25–40 KB/s). JSON nhỏ (<30 KB) mất 0.2s; JSON 4 MB mất 20–35s!
Rất nhanh (2ms - 8ms)

3. Ghi SQLite (WAL Mode)

Bật sẵn journal_mode = WAL + busy_timeout = 30s + ghi Nhật ký bất đồng bộ. Đọc & Ghi chạy song song không khóa nhau.
Đã tối ưu trước đó

4. POS, Hóa Đơn & Mở NCC

Tìm khách POS (compact=1), Tab Hóa Đơn (CTE + limit) và Ô chọn NCC Nhập hàng đã chạy tức thì (<0.2s).
