============================================================
           HƯỚNG DẪN SỬ DỤNG - POS MASTERCARE (PORTABLE)
============================================================

1. KHỞI ĐỘNG HỆ THỐNG:
   - Nhấp đúp vào file "POS_Mastercare.exe".
   - Hệ thống chạy hoàn toàn ngầm dưới nền, KHÔNG CÒN CỬA SỔ ĐEN vướng víu.
   - Biểu tượng logo Mastercare sẽ xuất hiện tại Khay hệ thống (System Tray) ở góc phải màn hình cạnh đồng hồ Windows.
   - Trình duyệt sẽ tự động mở trang bán hàng.
   - BẠN CÓ THỂ ĐÓNG TRÌNH DUYỆT BẤT KỲ LÚC NÀO, POS VẪN HOẠT ĐỘNG BÌNH THƯỜNG!

2. THAO TÁC QUA BIỂU TƯỢNG GÓC PHẢI (SYSTEM TRAY):
   - Nhấp đúp chuột trái vào icon: Mở ngay trang bán hàng.
   - Bấm chuột phải vào icon sẽ có menu tiện ích:
     + Bán Hàng POS (127.0.0.1:8998)
     + Mở POS qua Tailscale (pos-server:8998)
     + Tự khởi động cùng Windows (Tick chọn để bật/tắt)
     + Thoát POS Mastercare (Dừng hoàn toàn hệ thống)

3. TỰ ĐỘNG KHỞI ĐỘNG CÙNG WINDOWS:
   - Cách 1: Chuột phải vào icon Mastercare ở góc phải đồng hồ -> Chọn "Tự khởi động cùng Windows".
   - Cách 2: Nhấp đúp vào file "BAT_KHOI_DONG_CUNG_WINDOWS.bat".
   - Mỗi sáng khi bật máy tính lên, POS sẽ tự động chạy ngầm sẵn sàng 24/7 mà không cần ai phải bấm mở.

4. TRUY CẬP HỆ THỐNG:
   - Trên máy chủ: http://127.0.0.1:8998
   - Trên điện thoại / iPad / máy khác:
     http://pos-server:8998  (hoặc IP Tailscale 100.x.y.z:8998)

5. TẮT MÁY CHỦ:
   - Chuột phải vào icon góc phải chọn "Thoát POS Mastercare".
   - Hoặc nhấp đúp vào file "TAT_MAY_CHU.bat".
